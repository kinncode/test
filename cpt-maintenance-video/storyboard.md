**λ 的兩種意思**（論文同一個符號代表兩件事，全片要一眼分得出來）

- 損失規避係數一律寫成**單獨的 λ**，放在黃色小標籤（`--yellow-soft` 底）裡，旁邊加小字「損失規避」。

**數字**
- 畫面上一律顯示論文四捨五入後的數字：257 / 266 / 256 天；可靠度 0.7911 / 0.7720 / 0.7931；成本 16,923 / 29,243.6 / 108,496。

**標籤**
- 不是論文數據的示意數值，加灰色 `tag` 標「示意」。
- 由我們（讀者）依論文公式重算的數值，加灰色 `tag` 標「我們重算」。
- 截圖一律附 `caption_zh`（「論文 Fig. x.x：…」）。

**公式**
- 用 KaTeX，並標上論文的式號，例如「式 (3.4)」。
- Cc、Cp 寫成 `C_c`、`C_p`。

**常用公式**（在 scene 裡直接用 JS 算，所有參數都出自論文）

```
Weibull：R(t)=exp(-(t/α)^β)　F=1-R　f=(β/α)(t/α)^(β-1)·R　λ(t)=(β/α)(t/α)^(β-1)

CPT 參數（Table 4.3）：中性 (δ,γ,λ)=(1,1,1)；尋求 (0.97,0.91,1.53)；規避 (1.03,0.91,2.25)
```
