成品：`out/cpt_maintenance_explainer.mp4`（含旁白、背景音樂、內嵌字幕），另附 `out/subtitles.srt`。

## 我們如何確認內容正確

- `tools/model.py` 用論文的公式與參數重算全部結果，與論文一致：
  - 期望決策：τ\* = 256.85 天、16,922.9 元/天、R = 0.7914（論文 257 / 16,923 / 0.7911）。
  - 風險尋求：266.4 天，PV 29,243.6；風險規避：256.4 天，PV 108,495.7（論文 Table 4.4：266 / 29,243.6 與 256 / 108,496）。
  - 歷史資料案例：247,025 / 347,259 / 1,331,799（論文 Table 4.7：247,030 / 347,310 / 1,332,000）。
- 畫面上的曲線都由 `tools/make_data.py` 從同一套公式算出（`data.js`），不是手繪近似。
- 腳本經過 5 位讀者分段精讀，再經過兩位獨立審稿者對照論文頁面查核：一位查與論文是否一致，一位查背景知識。
- 畫面上標「我們重算」的，是依論文公式自行推算、論文沒有直接寫出的數字；標「示意」的是說明用的數值。

## 怎麼做出來的

與同一 repo 的 `coprog-video/` 相同的流程：

1. `script.json`：旁白腳本（字幕 `t`，語音用 `say`）。
2. `tools/tts.py`：產生 zh-TW 語音與時間軸，輸出 `timing.js` 與字幕。
3. `index.html` + `engine.js` + `scenes/*.js`：每一幀只由時間 `t` 決定（`seek(t)`）。
4. `tools/audio.py`：合成背景音樂、旁白時自動壓低音樂、響度正規化。
5. `tools/render.mjs`：Playwright 逐幀截圖 → FFmpeg 編碼 → 合併音軌。

## 重新產生

```bash
npm install
python3 tools/make_data.py      # 由論文公式產生 data.js
python3 tools/tts.py            # 旁白與時間軸（需要網路）
python3 tools/audio.py          # 音樂與混音 → out/audio.m4a
node tools/render.mjs snap 60 300   # 抽幀檢查 → build/snap/
node tools/render.mjs video 3   # 完整渲染
```

## 說明

- 標示「論文 Fig. / Table」的圖取自原論文，僅供學習。
- 原始 PDF 部分頁面（例如第 36 頁）有讀者事後加上的手寫註記，影片沒有使用那些頁面的截圖。
